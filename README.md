# Building with Claude 🛠️

This repo is my public record of what I build with the help of Claude (Anthropic's AI assistant). I give the instructions, ideas and topics; Claude helps me design, write and code. Every project is logged step by step, with the actual files, so anyone can see how it was made.

**Me:** Urmila Koli · MSc Data Analytics (Berlin School of Business and Innovation) · data analytics for finance and risk · Berlin

## How the repo is organised

```
building-with-claude/
├── README.md            ← you are here
├── COMMANDS_LOG.md      ← every request, in order, with what was built
├── learning/            ← lessons, study plans, learning tools
├── apps/                ← apps built for me
├── automations/         ← scheduled tasks and reminders
├── career/              ← CV, job search and portfolio work (added when used)
└── system/              ← how this record is kept
```

Each project folder has its own `README.md` with:
1. **The request**: what I asked for
2. **Steps**: how it was built, in order
3. **Files**: what each file does
4. **How to run or open it**
5. **What I learned**

## Tools used

- **Claude**, for planning, writing, code and testing
- **HTML, CSS and JavaScript**, for the lessons and apps (each is a single self-contained file)
- **Python**, for the build scripts that generate lessons from data
- **Claude artifacts**, for hosting the live pages
- **Scheduled tasks**, for the daily reminder

## Opening the files

The `.html` files run in any browser. Download one and double-click it, or open the live link in each project's README.
